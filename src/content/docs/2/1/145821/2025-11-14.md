## Relazione tensione-corrente dei dipoli nel dominio di $s$

| $t$                                                 | $s$                                                    |
| --------------------------------------------------- | ------------------------------------------------------ |
| $V_R(t) = R I_R(t)$                                 | $tilde(V)_R(s) = R tilde(I)_R(s)$                      |
| $I_R(t) = V_R(t) / R$                               | $tilde(I)_R(s) = tilde(V)_R(s) / R$                    |
| $V_C(t) = 1 / C integral_0^t I_C(t) dif t + V_C(0)$ | $tilde(V)_C(s) = 1 / C tilde(I)_C(s) / s + V_C(0) / s$ |
| $I_C(t) = C (dif V_C(t)) / (dif t)$                 | $tilde(I)_C(s) = C s tilde(V)_C(s) - C V_C(0)$         |
| $V_L(t) = L (dif I_L(t)) / (dif t)$                 | $tilde(V)_L(s) = L s tilde(I)_L(s) - L I_L(0)$         |
| $I_L(t) = 1 / L integral_0^t V_L(t) dif t + I_L(0)$ | $tilde(I)_L(s) = 1 / L tilde(V)_L(s) / s + I_L(0) / s$ |

## Impedenza nel dominio $s$

L'impedenza è molto simile a quella nel dominio delle frequenze quando le
condizioni iniziali sono nulle:

$$
Z = tilde(V)(s) / tilde(I)(s)
$$

Quindi:

- $Z_R = R$
- $Z_C = 1 / (s C)$
- $Z_L = s L$

## Equazioni differenziali nel dominio $s$

La risposta di un qualsiasi sistema LTI è data da un'espressione del tipo:

$$
sum_(n = 0)^N a_n (dif^n y(t)) / (dif t^n) = sum_(m = 0)^M b_m (dif^m x(t)) / (dif t^m)
$$

con i coefficienti $a_n$ e $b_m$ reali e con condizioni iniziali a $t = 0$.

Nel dominio di $s$, essa diventa:

$$
sum_(n = 0)^N a_n s^n tilde(Y)(s) - sum_(n = 0)^N (sum_(i = 1)^n s^(n - i) (dif^(i - 1) y(0)) / (dif t^(i - 1))) a_n &= tilde(A)(s) tilde(Y)(s) + tilde(E)(s) \
sum_(m = 0)^M b_m s^m tilde(X)(s) - sum_(m = 0)^M (sum_(i = 1)^m s^(m - i) (dif^(i - 1) x(0)) / (dif t^(i - 1))) b_m &= tilde(B)(s) tilde(X)(s) + tilde(D)(s)
$$

In pratica otteniamo una divisione tra polinomi:

$$
tilde(Y)(s) = (tilde(B)(s) tilde(X)(s) + tilde(D)(s) - tilde(E)(s)) / tilde(A)(s)
$$

### Anti-trasformazione del risultato

Per anti-trasformare bisogna ricondursi a qualcosa di più semplice, ad esempio
$1 / (s - d)$.

Ricombiniamo l'espressione di polinomi trovata sopra:

$$
tilde(Y)(s) = tilde(C)(s) / tilde(A)(s) = tilde(Q)(s) + tilde(R)(s) / tilde(J)(s) = tilde(Q)(s) + sum_(k = 1)^K O_k / (s - s_k^"zero")
$$

- richiediamo che il grado di $tilde(R)$ sia minore di quello di $tilde(J)$
- $s_k^"zero"$ è il $k$-esimo valore di $s$ che annulla il polinomio
  $tilde(J)(s)$.
- $O_k = lim_(s -> s_k^"zero") (s - s_k^"zero") tilde(R)(s) / tilde(J)(s)$

Quindi i passaggi diventano:

1. Troviamo gli zeri $s_k^"zero"$ di $tilde(J)(s)$.
2. Troviamo $O_k$.
3. Anti-trasformiamo.

Una volta che abbiamo trovato l'espressione semplificata di
$tilde(R)(s) / tilde(J)(s)$, possiamo anti-trasformare e otteniamo:

$$
sum_(k = 1)^K O_k e^(s_k^"zero" t)
$$
