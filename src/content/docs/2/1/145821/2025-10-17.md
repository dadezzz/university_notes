## Funzione di trasferimento

La funzione di trasferimento è il rapporto tra uscita e ingresso di un sistema
LTI sul dominio delle frequenze.

Possiamo applicarla al caso dei fasori di corrente visti nel circuito RLC in
parallelo nella scorsa lezione.

$$
tilde(H)(omega) = "uscita" / "ingresso" = tilde(I)_(R_1) / tilde(I)_s
$$

:::caution

Teoricamente, il segnale sinusoidale in ingresso dovrebbe essere stato presente
da $t = -oo$, poiché il circuito deve trovarsi in stato stazionario.

:::

**Esempio**: il circuito visto la scorsa lezione:

$$
tilde(H)(omega) &= (tilde(v)_s / R) / (tilde(v)_s / Z_"tot") \
                &= (1 / (1 / R + j omega C + 1 / (j omega L))) / R \
                &= 1 / (R (1 / R + j omega C - j 1 / (omega L))) \
                &= 1 / (R (1 / R + j (omega C - 1 / (omega L)))) \
                &= 1 / (1 + j R (omega C - 1 / (omega L)))
$$

A questo punto sostituiamo $omega_0 = 1 / sqrt(L C)$ e $Q = R sqrt(C / L)$,
notando che $R C = R sqrt(C / L) sqrt(L C) = Q / omega_0$.

$$
tilde(H)(omega) &= 1 / (1 + j R C (omega - 1 / (omega L C))) \
                &= 1 / (1 + j R C (omega - omega_0^2 / omega)) \
                &= 1 / (1 + j Q (omega / omega_0 - omega_0 / omega)) (1 - j Q (omega / omega_0 - omega_0 / omega)) / (1 - j Q (omega / omega_0 - omega_0 / omega)) \
                &= (1 - j Q (omega / omega_0 - omega_0 / omega)) / (1 + Q^2 (omega / omega_0 - omega_0 / omega)^2)
$$

Il modulo della funzione definisce il guadagno del circuito:

$$
G(omega) = abs(tilde(H)(omega)) &= sqrt((1 - j Q (omega / omega_0 - omega_0 / omega)) / (1 + Q^2 (omega / omega_0 - omega_0 / omega)^2) (1 + j Q (omega / omega_0 - omega_0 / omega)) / (1 + Q^2 (omega / omega_0 - omega_0 / omega)^2)) \
                                &= sqrt((1 - j Q (omega / omega_0 - omega_0 / omega)) (1 + j Q (omega / omega_0 - omega_0 / omega))) / (1 + Q^2 (omega / omega_0 - omega_0 / omega)^2) \
                                &= sqrt(1 + Q^2 (omega / omega_0 - omega_0 / omega)^2) / (1 + Q^2 (omega / omega_0 - omega_0 / omega)^2) \
                                &= 1 / sqrt(1 + Q^2 (omega / omega_0 - omega_0 / omega)^2)
$$

Il cambiamento di fase tra l'ingresso e l'uscita è dato da:

$$
theta(omega) = arg(tilde(H)(omega)) &= arctan(((1 + Q^2 (omega / omega_0 - omega_0 / omega)^2) (- Q (omega / omega_0 - omega_0 / omega))) / (1 + Q^2 (omega / omega_0 - omega_0 / omega)^2)) \
                                    &= arctan((- Q (omega / omega_0 - omega_0 / omega)) / 1) \
                                    &= - arctan(Q (omega / omega_0 - omega_0 / omega))
$$

## Valore RMS (Root Mean Square) di una sinusoidale

$$
X_"RMS" &= sqrt(1 / T integral_0^T A^2 cos(omega t + theta)^2 dif t) \
        &= sqrt(omega A^2 / (2 pi) integral_0^(2 pi / omega) cos(omega t + theta)^2 dif t) \
        &= sqrt(omega A^2 / (2 pi) integral_0^(2 pi / omega) (cos(2 omega t + 2 theta) + 1) / 2 dif t) \
        &= sqrt(omega A^2 / (4 pi) (2 pi) / omega) \
        &= sqrt(A^2 / 2) = A / sqrt(2)
$$

Nei circuiti a corrente alternata, il valore RMS di $V$ indica il valore
effettivo della tensione. Pertanto, un circuito a corrente continua con una
tensione $V$ e uno a corrente alternata con lo stesso valore RMS dissipano (per
effetto Joule) la stessa quantità di calore sulla stessa resistenza.
