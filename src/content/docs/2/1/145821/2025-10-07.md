## Circuiti RLC di 2° ordine a stato 0

Prendiamo un circuito dove a $t_0$ viene acceso un generatore di corrente $I_s$:

```
┌────┬────┬────┐
I_s  C_1  L_1  R_1
└────┴────┴────┘
```

Costruiamo il solito sistema:

$$
cases(
V(t) = V_(C_1)(t) = V_(L_1)(t) = V_(R_1)(t),
I_s(t) = I_(C_1)(t) + I_(L_1)(t) + I_(R_1)(t),
V_(R_1)(t) = I_(R_1)(t) R_1,
I_(C_1)(t) = C_1 (dif V_(C_1)(t)) / (dif t),
V_(L_1)(t) = L_1 (dif I_(L_1)(t)) / (dif t),
I_(L_1)(t_0) = 0,
V_(C_1)(t_0) = 0,
)
$$

Otteniamo una equazione differenziale simile a quella vista nelle lezioni
precedenti:

$$
cases(
I_s(t) = L_1 C_1 (dif^2 I_(L_1)(t)) / (dif t^2) + L_1 / R_1 (dif I_(L_1)(t)) / (dif t) + I_(L_1)(t),
I_(L_1)(t_0) = 0,
(dif I_(L_1)(t_0)) / (dif t) = 0,
)
$$

L'analisi ci dice che la soluzione di un'equazione differenziale non omogenea è
uguale alla soluzione dell'equazione omogenea corrispondente più una soluzione
particolare:

$$
I_(L_1)(t) = I_(L_1)(t)^H + I_(L_1)(t)^P
$$

### Caso particolare: $I_s(t) = theta(t)$

Per $t > t_0$:

$$
cases(
L_1 C_1 (dif^2 I_(L_1)(t)) / (dif t^2) + L_1 / R_1 (dif I_(L_1)(t)) / (dif t) + I_(L_1)(t) = 1,
I_(L_1)(t_0) = 0,
(dif I_(L_1)(t_0)) / (dif t) = 0,
)
$$

Riprendiamo l'equazione omogenea vista nell'ultima lezione. In tre casi su
quattro (escludendo il caso criticamente smorzato, che ha un'espressione
leggermente diversa), la soluzione si può scrivere come:

$$
I_(L_1)(t) = k_1 e^(x_1 t) + k_2 e^(x_2 t)
$$

Quindi la soluzione della nostra equazione non omogenea sarà:

$$
cases(
I_(L_1)(t) = (k_1 e^(x_1 t) + k_2 e^(x_2 t) + 1) theta(t),
I_(L_1)(t_0) = 0,
(dif I_(L_1)(t_0)) / (dif t) = 0,
)
$$

Per trovare $k_1$ e $k_2$ basta sfruttare le uguaglianze fornite dal problema di
Cauchy.

## Soluzione generale di una rete LTI

Data una rete LTI con un ingresso $x(t)$ e un'uscita $y(t)$, sarà sempre
possibile scrivere un'equazione differenziale di grado $n$ che mette in
relazione le due grandezze. Essa sarà del tipo:

$$
cases(
sum_(i = 0)^n a_i (dif^i y(t)) / (dif t^i) = sum_(i' = 0)^m b_(i') (dif^(i') x(t)) / (dif t^(i')),
y(t_0) = k_0,
dots.v,
(dif^(n - 1) y(t_0)) / (dif t^(n - 1)) = k_(n - 1),
)
$$
