# Teorema del limite di una funzione monotona

Se $f(n) = a_{n}$ è una funzione monotona e $f(i) in bb(R)$, allora:

$$
\exists\ \lim_{n -> +oo} f(n)
$$

Se $f(n)$ è crescente, allora $f(n) -> sup \Set{f(n)}$, se decrescente
$f(n) -> inf \Set{f(n)}$.

# Limiti di funzioni elementari

Con $n in \N$:

- $\lim_{x -> x_{0}} x^{n} = x_{0}^{n}$
- $\lim_{x -> +oo} x^{n} = +oo$
- $\lim_{x -> -oo} x^{n} = \begin{cases} \text{n pari} \implies +oo \\ \text{n dispari} \implies -oo \end{cases}$

Con $a in bb(R)$:

- $\lim_{x -> x_{0}} x^{a} = x_{0}^{a}$ (se $x_{0} > 0$)
- $\lim_{x -> +oo} x^{a} = \begin{cases} a > 1 \implies +oo \\ 0 < a < 1 \implies 0 \end{cases}$
- $\lim_{x -> -oo} x^{a} = \begin{cases} a > 1 \implies 0 \\ 0 < a < 1 \implies +oo \end{cases}$

Con $a > 0$:

- $\lim_{x -> x_{0}} a^{x} = a^{x_{0}}$
- $\lim_{x -> +oo} a^{x} = \begin{cases} a > 1 \implies +oo \\ 0 < a < 1 \implies 0 \end{cases}$
- $\lim_{x -> -oo} a^{x} = \begin{cases} a > 1 \implies 0 \\ 0 < a < 1 \implies +oo \end{cases}$
- $\lim_{x -> x_{0}} \log_{a}(x) = \log_{a}(x_{0})$
- $\lim_{x -> +oo} \log_{a}(x) = \begin{cases} a > 1 \implies -oo \\ 0 < a < 1 \implies +oo \end{cases}$

- $\lim_{x -> -oo} \log_{a}(x) = \begin{cases} a > 1 \implies +oo \\ 0 < a < 1 \implies -oo \end{cases}$

Funzioni trigonometriche:

- $\lim_{x -> x_{0}} sin(x) = sin(x_{0})$ (se $x_{0} in bb(R)$)
- $\lim_{x -> x_{0}} cos(x) = cos(x_{0})$ (se $x_{0} in bb(R)$)
- $\lim_{x -> x_{0}} tan(x) = tan(x_{0})$ (se
  $x_{0} in (- \frac{\pi}{2}, \frac{\pi}{2})$)
- $\limsup_{x -> \frac{\pi}{2}} tan(x) = +oo$
- $\liminf_{x -> \frac{\pi}{2}} tan(x) = -oo$

# Teorema del cambio della variabile del limite

$$
\lim_{x -> 0} x = \begin{cases}
y = \frac{1}{x} \\
\lim_{y -> oo} y
\end{cases}
$$

**Esempio**:

Risolvere $\lim_{x -> 0} \left(1 + \frac{1}{\frac{1}{x}}\right)^{\frac{1}{x}}$.

Notiamo che scambiando $x$ con $\frac{1}{x}$ otterremmo il limite notevole che
ha come risultato il numero di Eulero.

$$
\lim_{x -> 0} \left(1 + \frac{1}{\frac{1}{x}}\right)^{\frac{1}{x}} = \begin{cases} y = \frac{1}{x} \\ \lim_{y -> +oo} \left(1 + \frac{1}{y}\right)^{y} = e \end{cases}
$$
