## Restrizione di una funzione

Data $f: A -> B$, la restrizione $f_{\vert D}$ definisce la funzione solo nel
sottoinsieme $D \subset A$.

**Esempio**:

- $f: bb(R) -> bb(R), \ f(x) = \lfloor x \rfloor$: non è iniettiva.
- $D = \N, \ f_{\vert D}: \N -> bb(R), \ f(x) = \lfloor x \rfloor$: è iniettiva.

Di solito la restrizione si usa per fare in modo che una funzione acquisisca
certe proprietà in un determinato intervallo.

## Funzioni limitate

- funzione limitata superiormente:
  $\exists\ M in bb(R) \mid \forall\ x in bb(R), f(x) <= M$;
- funzione limitata inferiormente:
  $\exists\ m in bb(R) \mid \forall\ x in bb(R), f(x) >= m$;
- funzione limitata: è una funzione limitata sia superiormente che
  inferiormente;

## Funzioni simmetriche

- funzione pari: $f(x) = f(-x)$ (primo e secondo quadrante specchiati);
- funzione dispari: $f(-x) = -f(x)$ (prime e terzo quadrante specchiati);
- funzione periodica: $\exists\ T in bb(R), k in \Z \mid f(x + k\ T) = f(x)$;
- funzione inversa nel piano cartesiano: $\text{graf}(f^{-1})$ è simmetrico a
  $\text{graf}(f)$ rispetto alla retta $y = x$.

## Funzioni monotone

- crescente: $x_1, x_2 in bb(R),\ x_1 < x_2 \implies f(x_1) <= f(x_2)$;
- strettamente crescente:
  $x_1, x_2 in bb(R),\ x_1 < x_2 \implies f(x_1) < f(x_2)$;
- decrescente: $x_1, x_2 in bb(R),\ x_1 < x_2 \implies f(x_1) >= f(x_2)$;
- strettamente decrescente:
  $x_1, x_2 in bb(R),\ x_1 < x_2 \implies f(x_1) > f(x_2)$;
