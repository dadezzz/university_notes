# Forme determinate delle operazioni tra limiti

## Addizione

- $a + (\pm oo) = \pm oo$
- $(\pm oo) + (\pm oo) = \pm oo$

## Moltiplicazione

Con $a > 0$:

- $a\ (\pm oo) = \pm oo$
- $\frac{a}{\pm oo} = 0$
- $\frac{1}{0^{\pm}} = \pm oo$

## Esponenziali

Con $a > 1$:

- $a^{+oo} = +oo$
- $a^{-oo} = 0$
- $0^{\pm oo} = 0$

Se la base non è $>= 0$, non tutte le potenze sono definite.

# Forme indeterminate delle operazioni tra limiti

## Addizione

- $+oo - oo$

## Moltiplicazione

- $oo\ 0$
- $\frac{oo}{oo}$
- $\frac{0}{0}$

## Esponenziali

- $1^{oo}$
- $oo^{0}$
- $0^{0}$

## Tecniche algebriche per risolvere limiti indefiniti

### Somma e sottrai

$$
\begin{array}{l}
\lim_{n -> +oo} \frac{n}{n + 1} = \\[10pt]
\lim_{n -> +oo} \frac{n + 1 - 1}{n + 1} = \\[10pt]
\lim_{n -> +oo} \frac{n + 1}{n + 1} - \frac{1}{n + 1} = \\[10pt]
\lim_{n -> +oo} 1 - \frac{1}{n + 1}
\end{array}
$$

### Raccogli chi comanda

$$
\begin{array}{l}
\lim_{n -> +oo} n^{2} - n + n^{3} = \\[5pt]
\lim_{n -> +oo} n^{3} \left(\frac{1}{n} - \frac{1}{n^{2}} + 1 \right) = \\[10pt]
\lim_{n -> +oo} n^{3} (0 - 0 + 1) = \\[5pt]
\lim_{n -> +oo} n^{3}
\end{array}
$$

### Moltiplica e dividi

$$
\begin{array}{l}
\lim_{n -> +oo} \left(1 + \frac{1}{2n^{2} - 1}\right)^{3n^{2} + 1} = \\[10pt]
\lim_{n -> +oo} \left(1 + \frac{1}{2n^{2} - 1}\right)^{3n^{2} + \frac{2n^{2} - 1}{2n^{2} - 1}} = \\[10pt]
\lim_{n -> +oo} \left(1 + \frac{1}{2n^{2} - 1}\right)^{2n^{2} - 1 + \frac{3n^{2} - 1}{2n^{2} - 1}} = \\[10pt]
\lim_{n -> +oo} e^{\frac{3n^{2} + 1}{2n^{2} - 1}}
\end{array}
$$

### Moltiplica, dividi e razionalizza

$$
\begin{array}{l}
\lim_{n -> +oo} \sqrt{n + 1} - \sqrt{n - 1} = \\
\lim_{n -> +oo} \frac{(\sqrt{n + 1} - \sqrt{n - 1})(\sqrt{n + 1} + \sqrt{n - 1})}{\sqrt{n + 1} + \sqrt{n - 1}} = \\[10pt]
\lim_{n -> +oo} \frac{(n + 1) - (n - 1)}{\sqrt{n + 1} + \sqrt{n - 1}} = \\[10pt]
\lim_{n -> +oo} \frac{2}{\sqrt{n + 1} + \sqrt{n - 1}}
\end{array}
$$
