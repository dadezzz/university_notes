## Base di uno spazio vettoriale

Sia $V$ uno spazio vettoriale finitamente generato, l'insieme di vettori
$\mathcal{B} = \Set{bold(b)_{1}, ..., bold(b)_{n}}$ è detto base di $V$ se:

- è un insieme di generatori di $V$;
- è linearmente indipendente;

$\forall\ bold(v) in V$ corrisponde ad un'unica combinazione lineare dei vettori
della base $\Set{bold(b)_{1}, ..., bold(b)_{n}}$.

Dati un insieme di vettori
$\Set{bold(v)_{1}, ..., bold(v)_{k}} \subseteq bb(R)^{m}$ e la matrice
$bold(A) in \mathbb{M}_{m,n}(bb(R)) = \left[\begin{array}{c|c|c} bold(v)_{1} & ... & bold(v)_{n} \end{array}\right]$:

- $\Set{bold(v)_{1}, ..., bold(v)_{n}} in bb(R)^{m}$ è un sistema di generatori
  di $bb(R)^{n}$ se e solo se $rg(bold(A)) = m, \ n >= m$.
- $\Set{bold(v)_{1}, ..., bold(v)_{n}} in bb(R)^{m}$ è linearmente indipendente
  se e solo se $rg(bold(A)) = n, \ n <= m$.
- $\Set{bold(v)_{1}, ..., bold(v)_{n}} in bb(R)^{m}$ è una base di $bb(R)^{m}$
  se e solo se $rg(bold(A)) = m = n$.
