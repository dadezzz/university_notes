# AGENTS.md

ICE Notes – Astro + Starlight docs site for university course notes.

## Commands

```
pnpm install          # Install deps
pnpm dev              # Dev server (hot reload, --host flag)
pnpm build            # Production build → dist/
pnpm check            # TypeScript type-check (astro check)
pnpm lint:check       # Biome lint
pnpm lint:fix         # Biome lint --fix
pnpm format:check     # Biome format + Prettier check
pnpm format:fix       # Biome format --fix + Prettier write
pnpm clean            # Remove .astro/, .pnpm-store/, dist/, node_modules/
```

## Content structure

```
src/content/docs/
    _templates/starlight.typ   # Shared show rules + note/aside helpers
    [course]/
        course.json            # { code, name, professors[], lang }
        YYYY-MM-DD.typ         # Individual lecture notes
        images/                # Local images referenced by the notes
```

- Notes are written in **Typst**, not Markdown. The custom loader in
  `src/content.config.ts` compiles them to HTML (see “Math / Typst” below).
- Courses live in a flat `[course]/` layout. The `courses` glob only matches
  `*/course.json`, so leftovers of the old `[year]/[semester]/[code]/` tree are
  ignored until migrated.
- The sidebar is auto-generated by Starlight; no `sidebar` entry is needed in
  `astro.config.ts` for new courses.
- Note metadata is declared with a `#metadata((...))` block (`lang`, `title`,
  `description`, `prev`) and parsed by the loader. `lang` and `title` are
  required by the `docs` schema.
- `_templates/` is skipped by the loader (its id is checked in
  `syncTypstDocEntry`) and must not contain note files.

## Rendering pipeline

- `src/content.config.ts` shells out to the `typst` CLI (v0.15+) per entry:
  `typst compile --format html` for the body and `typst eval` for metadata and
  image paths. Output is cached in the content store and refreshed through the
  Vite watcher (`change`/`add`/`unlink`).
- The stored HTML is only the inner content of Typst's `<body>`.
- `src/pages/[course]/[date].astro` post-processes that HTML (Shiki, heading
  ids, Starlight heading links/asides) and renders it inside `StarlightPage`.
- `patches/@astrojs__starlight.patch` makes `TableOfContentsList` render heading
  text with `set:html` so TOC entries keep inline HTML from Typst.

## Math / Typst

- Math is rendered by **Typst**, not KaTeX or LaTeX.
- `_templates/starlight.typ` defines the shared `setup` show rule. It polyfills
  `math.overline`/`math.underline` (Typst does not yet emit them in MathML) and
  wraps `math.equation` in `<span class="not-content">` so Starlight prose
  styles do not distort the math (see `src/styles/math-blocks.css`).
- Notes use **Typst math syntax** (e.g. `sqrt(...)`, `bb(R)`, `cases(...)`,
  `op("rect")(...)`) instead of LaTeX commands.
- Inline math: `$x$`. Display math: `$ x $` (spaces around the expression).
- Compile errors are logged by the loader and the entry is skipped; the old
  `.typst-math-error` markup and its (already commented-out) CI check no longer
  exist.
- Typst inlines images as base64 data URIs in the exported HTML, so pages can
  become large. `getImagePaths` collects the sources for future asset handling
  but they are not rewritten yet.

## Tooling quirks

- **Two formatters**: Biome (JS/TS/`.astro`) + Prettier (`.md`). Prettier
  ignores `.astro` (see `.prettierignore`); Biome's HTML formatter handles those
  files. Run both with `pnpm format:fix`.
- Prettier uses `proseWrap: "always"` for `.md`.
- Biome HTML formatting is enabled via `experimentalFullSupportEnabled` in
  `biome.jsonc`.
- Biome has `noFloatingPromises` and `noMisusedPromises` as errors.
- `.astro` files: `noUnusedImports` is turned off in Biome.
- `pnpm-workspace.yaml` sets `allowBuilds` and `patchedDependencies` (the
  Starlight patch in `patches/`) – no workspace packages.

## Deployment

- Dockerfile builds with pnpm, serves `dist/` via Caddy.
- `docker-compose.yaml` deploys behind Traefik (not used locally).
- `.releaserc.json` uses semantic-release on `main` with `commit-analyzer`.

## Review skills

Located under `.agents/skills/`:

- `document-content-review`: factual/logical errors
- `document-grammar-review`: grammar, spelling, style
- `document-description`: frontmatter title/description generation

## Language policy

Notes are written in the language of instruction (Italian for early courses,
English for later courses). Never translate notes between languages.
